# GWNB js2

Новая версия проекта на ES-модулях и классах.

## Запуск

1. Откройте `index-js2.html` в браузере.
2. Управление:
   - `WASD` / стрелки: движение
   - ЛКМ: стрельба
   - ПКМ: рывок/прыжок

## Архитектура

- `core/` — базовый ECS-рантайм (`Entity`, `World`, `System`, `GameApp`, `Scene`)
- `components/` — данные сущностей
- `systems/` — игровая логика (инпут, AI, физика, коллизии, урон, рендер)
- `prefabs/` — фабрика игровых объектов и ассеты
- `scenes/` — композиция уровня/режима
- `managers/` — менеджеры слоев и ввода
- `utils/` — общие константы и утилиты

## Принципы

- Компоненты хранят только данные.
- Поведение находится в системах.
- Все связи между системами идут через `World.events`.
- Фабрика создает только сущности и их наборы компонентов.
